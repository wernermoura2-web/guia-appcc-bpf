Trabalho em grupo — BPF/APPCC

Os integrantes trabalham em seus aparelhos e compartilham arquivos JSON da mesma inspeção. O responsável incorpora apenas os processos escolhidos. Não há edição simultânea nem sincronização automática entre computadores.

Preparar a inspeção

  1. Abra Trabalho em grupo pelo menu principal.
  2. Preencha a envasadora, o endereço e a data. Cadastre os inspetores.
  3. No botão Trabalho em equipe, use Gerar arquivo inicial da equipe.
  4. Envie o mesmo JSON a todos. Cada colega abre o modo em grupo e usa Abrir preenchimento para carregar esse arquivo.

O código comum identifica a inspeção. Gerar o arquivo inicial não limpa o guia. Todos devem manter a identificação da envasadora, endereço e data iguais às do arquivo inicial.

Dividir o trabalho

IntegranteDivisão sugerida
Pessoa 1Captação, condução e reservatórios.
Pessoa 2 — consolidaçãoControle de qualidade, responsáveis e dados gerais.
Pessoa 3Recepção, higienização de embalagens e envase.

A equipe pode combinar outra divisão. Cada colega responde às frases pelo botão F e usa Salvar arquivo para baixar o JSON e encaminhá-lo ao responsável.

Importar e consolidar

  1. O responsável usa Importar processos e seleciona um ou mais JSONs recebidos.
  2. Confira o nome do arquivo e marque somente os processos que esse colega avaliou.
  3. Escolha apenas um arquivo de origem para cada processo. Um processo inclui todas as suas linhas e unidades.
  4. Use Importar processos selecionados. Respostas e observações dos processos marcados são substituídas pelas do arquivo recebido; os demais processos são preservados.
  5. A opção Dados gerais incorpora observações gerais, fotos, rótulos, responsáveis e lista documental do arquivo escolhido. Os dados da envasadora permanecem os do arquivo inicial.
  6. Confira a matriz e as considerações finais, complete os dados gerais e use Salvar arquivo para guardar o consolidado. Use Imprimir / PDF para a versão impressa.

O menu Trabalho em equipe mostra os arquivos incorporados e os processos importados. Arquivos com código de inspeção ou identificação diferentes não são incorporados.

Guardar e recuperar

O preenchimento individual e o preenchimento em grupo têm rascunhos e cópias automáticas separados. Use Cópias de segurança automáticas para guardar ou recuperar cópias do modo em grupo; exporte também o JSON para outro local.

Abrir preenchimento restaura o guia inteiro. Importar processos substitui apenas as partes selecionadas. Não use Novo / limpar tudo depois de abrir o JSON inicial, pois isso cria outra inspeção.

Os cadastros de envasadoras e inspetores podem ser exportados e importados pelos respectivos menus. O JSON da inspeção transporta os dados utilizados nessa inspeção, sem transferir automaticamente todo o cadastro do aparelho.
